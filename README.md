# Week 06 - Flutter Notice Lab

## 1. 프로젝트 소개

Flutter를 이용하여 공지사항을 요청하고, 요청 상태에 따라 화면을 표시하는 앱입니다.

이 프로젝트에서는 `Future`와 `async/await`를 활용하여 비동기 요청을 처리하고, 로딩·성공·실패 상태 및 재시도 기능을 구현했습니다.

## 2. 주요 기능

- 초기 화면 표시
- 공지사항 요청 중 로딩 표시
- 요청 성공 시 공지사항 표시
- 요청 실패 시 오류 메시지 표시
- 실패 후 재시도 기능
- 요청 횟수 표시
- 요청 처리 중 중복 요청 방지
- `mounted` 확인을 통한 비동기 작업 후 위젯 상태 변경 보호

## 3. 개발 환경

- Framework: Flutter
- Language: Dart
- 실행 환경: Windows / Chrome
- 패키지: 기존 Flutter 프로젝트 구성 사용

## 4. 실행 방법

### 1) 저장소 복제

```bash
git clone https://github.com/chuns3hun/week06_notice_lab.git
cd week06_notice_lab
```

### 2) 패키지 확인

```bash
flutter pub get
```

### 3) 코드 분석

```bash
flutter analyze
```

### 4) Chrome에서 실행

```bash
flutter run -d chrome
```

## 6. 비동기 처리

공지사항 요청에는 하나의 비동기 결과를 반환하는 `Future`를 사용했습니다.

`async/await`를 이용해 요청이 완료될 때까지 기다리는 동안에도 UI가 로딩 상태를 표시할 수 있도록 구성했습니다.

요청 중에는 중복 요청을 방지하고, 요청 성공과 실패에 따라 화면 상태를 변경하도록 구현했습니다.

## 7. 테스트 한계 및 추가 확인 사항

- 공지사항 요청은 현재 Mock 서비스를 사용합니다.
- 실제 서버와 통신하는 기능은 검증하지 않았습니다.
- 요청 성공 또는 실패는 Mock 서비스의 결과에 따라 달라집니다.
- A/B 요청 비교, 사용 모델, 응답 차이 및 선택 이유는 별도 기록이 필요합니다.
- `flutter analyze`의 종료 코드는 별도로 기록하지 않았습니다.
